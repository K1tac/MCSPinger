# MCSPinger

Ping a Minecraft Server and get info on it.

## How it returns
```
-- Velocity 1.7.2-26.2 --
🌐 Online Status: Online
📢 MOTD: DonutSMP.net ѕᴜʀᴠɪᴠᴀʟ
👥 Player Count: 36366/60000
🛜 IP: donutsmp.net:25565
```

## Usage Example
```❯ ~/CLionProjects/Minecraft-Server-Pinger/cmake-build-debug/Minecraft_Server_Pinger donutsmp.net```
